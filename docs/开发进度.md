## 已经做完、实测通过的

建团、批量选照片、三通道离线识别、四道校验（校验码 / 日期码 / 地区码 / 性别生日交叉）、人工兜底页（原图可缩放、号码边输边校验）、绿色打勾。

导出：列可选可排序、实时预览、xlsx（自写 OOXML，身份证号强制文本格式，防止 Excel 显示成科学计数法）、txt（UTF-8 带 BOM、Tab 分隔、CRLF）、直连微信分享。生成的文件用 openpyxl 读回来验过。

团管理：右上角「编辑」进编辑模式，成员可逐条删（红叉 + 确认）；长按团条目可改名、选出发/结束日期（系统日期选择器，全中文）、写备注、删整团。

标签：长按成员弹标签框，全局标签库，十种预置颜色各不同；右上角加号可现场新建，颜色自动往后排并自动勾上；编辑模式下每个标签带小红叉可直删（不确认），底部按钮变「清除全部标签」并二次确认。

日志：本机脱敏（号码只留前 3 后 2，姓名不落盘）、按天文件、超 2 MB 切分、7 天自动清理（改 mtime 实测过）、崩溃捕获。

自动更新：`/releases` 列表（不是 `/releases/latest`，后者只有 prerelease 时返回 404）、下载、sha256 + 包名 + 签名三道校验、拉起系统安装。从 0.4.1 → 0.4.2 完整跑通过。Manifest 必须有 `REQUEST_INSTALL_PACKAGES`。

数据库：v4。v1→v2 加 team.endDate，v2→v3 预置标签，v3→v4 重排标签颜色下标。每次升级都是覆盖安装、老数据保住了。

模拟器：AVD `tourtest`，系统语言已改中文（`persist.sys.locale=zh-CN` + `settings put system system_locales zh-CN` + reboot）。窗口位置用 `tools/start-emulator.ps1` 钉住，别直接起。

## 构建与发布

```powershell
# 环境
$env:JAVA_HOME="D:\AIsoft\jdk17"
$env:ANDROID_HOME="D:\AIsoft\AndroidSdk"
# 构建（gradle 在 D:\AIsoft\gradle-8.9）
cd D:\AIsoft\projects\tour-tool
gradlew.bat :app:assembleRelease
```

版本号：versionName 从 0.0.5 起只动最后一位；versionCode 每次单独 +1（必须单调递增，否则覆盖安装报 `INSTALL_FAILED_VERSION_DOWNGRADE`）。

发布：算 sha256 → `gh release create v0.0.X dist/tour-tool-0.0.X.apk dist/tour-tool-0.0.X.apk.sha256`。

签名：`D:\AIsoft\keys\tour-tool\release.keystore`，`signing.properties` 在工程根目录（已 gitignore）。**这两个丢了以后所有手机都装不上更新**。
