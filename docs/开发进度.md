## 已经做完、实测通过的

**识别**：建团 → 批量选照片 → 三通道离线识别 → 四道校验（校验码 / 日期码 / 地区码 / 性别生日交叉）→ 人工兜底页（原图可缩放、号码边输边校验、绿色打勾）。8 张正样本 + 3 张负样本实测 8/8 自动通过。

**手机号**：每人在编辑页补填，11 位校验（多输少输都当场红字报出位数并禁用保存），名单卡片上显示一行手机号，已填的在绿勾前挂绿色电话图标。

**标签**：长按成员弹标签框，全局标签库，每种标签独立底色（12 色调色板），右上角加号现场新建（颜色自动往后排、自动勾上），编辑模式下每个标签带红叉可直删，批量「清除全部标签」要二次确认。

**团管理**：右上角「编辑」进编辑模式逐条删成员；长按团条目改名、选起止日期（系统日期选择器全中文）、写备注、删整团。

**导出**：列可选可排序（默认七列：序号/姓名/性别/证件类型/证件号码/出生日期/手机）、实时预览、xlsx（自写 OOXML，号码强制文本格式）、txt（UTF-8 BOM、Tab 分隔、CRLF）、底部两个按钮——「保存到本地」写进手机下载文件夹（覆盖同名）、「分享」直跳微信；结果提示固定在按钮上方。

**关于页**：开发人员、版本号、更新日志、检查更新（强制刷新）、错误日志（打包分享）、用户隐私与协议（与首启屏共用同一份文本）、开源许可（第三方 + MIT 全文）、免责声明（七条法律语言）。

**日志**：本机脱敏（号码只留前 3 后 2，姓名不落盘）、单线程异步写盘、按天文件、超 2 MB 切分、7 天自动清理、崩溃时先 flush 再退出。

**自动更新**：`/releases` 列表（不是 `/releases/latest`，后者只有 prerelease 时 404）、下载、sha256 + 包名 + 签名三道校验、拉起系统安装；6 小时内不重复查。Manifest 必须有 `REQUEST_INSTALL_PACKAGES`。

**数据库**：v5。v1→v2 加 team.endDate，v2→v3 预置标签，v3→v4 重排标签颜色下标，v4→v5 加 member.phone。每次都是覆盖安装、老数据保住。

**性能**：OCR 三通道串行、每刻只活一份图；解码上限 2600；引擎随 ViewModel 关闭；首页人数一条 GROUP BY；相册图按 EXIF 转正。

## 已知没做、不着急的

- 结束日期为空时无法单独清除（只能重选）

- APK 48.6 MB，主要是 ML Kit 中文模型；开 R8 能瘦一点但 ML Kit 靠反射加载模型，风险大于收益
- 错误日志只导出，没做「就地查看全文」

## 构建与发布

```powershell
$env:JAVA_HOME="D:\AIsoft\jdk17"
$env:ANDROID_HOME="D:\AIsoft\AndroidSdk"
cd D:\AIsoft\projects\tour-tool
gradlew.bat :app:assembleRelease
```

版本号：versionName 从 0.1.0 起只动最后一位（0.1.1、0.1.2…）；versionCode 每次单独 +1（必须递增，否则覆盖安装报 `INSTALL_FAILED_VERSION_DOWNGRADE`）。

发版四步：改 versionName/versionCode → 在 `ui/about/LegalText.kt` 的 CHANGELOG 加一条 → 构建 → 算 sha256 发 Release（tag 写 v0.1.X，附 apk + .sha256）。交付件重命名成 `旅游登记工具_<版本>.apk` 放 `D:\下载\`。

签名：`D:\AIsoft\keys\tour-tool\release.keystore`，`signing.properties` 在工程根（已 gitignore）。**丢了以后所有手机都装不上更新**。
